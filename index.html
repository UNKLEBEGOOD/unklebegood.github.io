35.19 minaverage wait, 5.19 over the 30-minute target

Wellspring Clinics Performance Analysis

Analyzed 420 visits across six Wellspring clinics in the Abuja area to understand waiting times, follow-ups and revenue. Cleaned four messy tables in Python (pandas): removed duplicate records, standardized consultation fees written 18 different ways, parsed dates in four formats, and set impossible negative waiting times to missing instead of guessing. Built a three-page Power BI dashboard and checked that the totals match across every page. Found an average wait of 35.19 minutes (5.19 over the 30-minute target), a 45.24% follow-up rate that ranged from 54% to 32% between clinics, and ₦3.10M in total revenue.

Python, pandas, Power BI, DAX

Medical Appointment No-Show Analysis

Analyzed 110,521 medical appointment records to explore patterns related to missed appointments. Cleaned and analyzed the data using Python (pandas), validated findings with SQL Server (T-SQL), and created an interactive Power BI dashboard. Explored factors such as SMS reminders, waiting time, gender, health conditions, and neighbourhood. Found an overall no-show rate of 20.2%, with higher observed no-show rates among patients who received SMS reminders and noticeable differences across neighbourhoods.

Python, SQL Server (T-SQL), Power BI

Healthcare Claims and Billing Analysis

Analyzed 70,000 billing records across 7 insurance payers to uncover where revenue was being lost in the claims cycle. Built an end-to-end pipeline in Python (pandas) and SQL Server (T-SQL, cross-validated), then designed a Power BI dashboard to track denials and collections. Found a $40M revenue gap (64.5% collection rate) driven mainly by preventable submission errors, such as duplicate claims and missing prior authorizations, rather than payer-specific issues.

Python, SQL Server (T-SQL), Power BI
